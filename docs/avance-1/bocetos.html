Formatos admitidos: .cs para código y capturas para OCR. Los nombres se sanean y los archivos se guardan con nombre GUID dentro de App_Data/uploads/año-mes.

Objetivo

  • Asociar una entrega a un estudiante y un grupo.
  • Elegir comparación directa o contra todo el corpus.
  • Guardar el resultado para consulta y tendencias.

Lógica y validaciones

  • Exige grupo, estudiante y al menos un archivo válido.
  • Rechaza extensiones no admitidas y archivos vacíos o gigantes.
  • El análisis es asíncrono y muestra progreso y errores visibles.
  • Sin grupo creado, ofrece ir a Grupos.

Objetivo

  • Explicar por qué la entrega se parece a otra.
  • Mostrar el diff línea a línea lado a lado.
  • Documentar observaciones y generar un quiz personalizado.

Lógica y validaciones

  • Similitud = 55 % tokens + 25 % shingles + 20 % líneas.
  • La IA se presenta como señal explicable, no como veredicto.
  • Metadatos: hash, propietario, fechas y codificación.
  • Quiz de 3–5 preguntas según estructura y métricas del código.
